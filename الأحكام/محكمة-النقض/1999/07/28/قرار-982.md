# محكمة النقض السورية: قرار 982 أساس 854 تاريخ 1999-07-28

القضية 854 أساس لعام 1999

قرار 982 لعام 1999

تاريخ 28/7/1999

محكمة النقض الغرفة المدنية السادسة

المبدأ: جمارك تربية أغنام تسديد البيان الجمركي بها.

إذا لم يسدد مربي الأغنام البيان الجمركي بها تعرض للمخالفة المتضمنة عدم سداد البيان الجمركي.

عام 2000 / العدد 3-4 / المبدأ: جمارك المخبأ السري وثبات المواطن.
