# محكمة النقض السورية: قرار 1024 أساس 1816 تاريخ 1999-07-28

القضية 1816 أساس لعام 1999

قرار 1024 لعام 1999

تاريخ 28/7/1999

محكمة النقض الغرفة المدنية السادسة

المبدأ: جمارك سيارة مدخلة مؤقتاً تعطلها.

تعطل السيارة المدخلة مؤقتاً لا يصلح عذراً أو قوة قاهرة لعدم سداد التعهد بإخراجها.

عام 2000 / العدد 3-4 / المبدأ: جمارك أصول حجية الحكم الناقض.
